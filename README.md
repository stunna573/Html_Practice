# HTML & CSS Portfolio

A dedicated portfolio for markup and styling practice. This repository contains HTML documents, CSS stylesheets, and the image/SVG assets used by the pages. JavaScript source files are maintained separately in the JavaScript Portfolio.

## What this repository demonstrates
- HTML page structure and semantic elements
- Forms, tables, navigation, and reusable page sections
- CSS selectors, pseudo-elements, combinators, and layout techniques
- Multi-page website layouts and styling
- Asset organization for front-end pages

## Structure
- `exercises/`: HTML fundamentals, assignments, CSS practice, and component exercises
- `projects/`: StayNest iterations, personal portfolio, cooking template, budgeting pages, calculator, and other practical projects
- `assets/`: reference images not tied to a single project

## How to view the pages
1. Open a project folder.
2. Open its main `.html` file in a browser, or use VS Code Live Server.
3. Keep relative asset paths unchanged when moving files.

## JavaScript companion
Some pages rely on JavaScript files that live in the separate JavaScript Portfolio. For full interactive behavior, combine the matching scripts with the HTML/CSS project files. See `PROJECT_COMPANIONS.md`.

## Notes
- Original HTML/CSS and supporting assets are preserved, including separate StayNest iterations.
- Git internals, editor metadata, macOS metadata, and `.DS_Store` files are excluded.
- Experimental and unfinished exercises remain grouped as practice rather than being presented as finished applications.
